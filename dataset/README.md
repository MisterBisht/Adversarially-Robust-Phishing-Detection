# Dataset Information

This project uses two publicly available phishing URL datasets hosted on Hugging Face.

## 1. Dataset Sources

**Dataset 1: ealvaradob/phishing-dataset**

Source: https://huggingface.co/datasets/ealvaradob/phishing-dataset

**Dataset 2: kmack/Phishing_urls**

Source: https://huggingface.co/datasets/kmack/Phishing_urls

## 2. Dataset Loading

Both datasets are accessed directly from Hugging Face through the Jupyter Notebook using the Hugging Face `datasets` library.

The original datasets are not stored locally in this repository.

## 3. Data Processing

Dataset loading, preprocessing, and preparation are performed within the project notebook.

## 4. Dataset Splitting

The notebook handles the preparation of training, validation, and testing data.

The generated splits will be documented separately when exported from the notebook.

## 5. Note

The original datasets are publicly available through their respective Hugging Face links.
