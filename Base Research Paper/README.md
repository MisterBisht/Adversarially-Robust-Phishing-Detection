# Reference Research Papers

This project is based on the study of existing research in malicious URL detection and phishing website classification.

## Paper 1

**Title:** Continuous Multi-Task Pre-Training for Malicious URL Detection and Webpage Classification

**Year:** 2025

**DOI:** https://doi.org/10.1016/j.comnet.2025.111513

**Publisher:** Elsevier (Computer Networks)

**Research Focus:** Malicious URL detection and webpage classification using multi-task pre-training.

## Paper 2

**Title:** Detecting Phishing Websites Through Improving Convolutional Neural Networks with Self-Attention Mechanism

**Year:** 2024

**DOI:** https://doi.org/10.1016/j.asej.2024.102643

**Publisher:** Elsevier

**Research Focus:** Phishing website detection using CNN and Self-Attention mechanisms.

## Purpose

These papers were selected as initial references for understanding existing phishing detection approaches and identifying opportunities for improvement in our proposed system.
